# Kouler

Kouler is a STOS sovereign bounded atomic-replacement caller.

Version: 0.1.0-source

Its first profile exists solely for the certified October 5, 2026 Main Directory recovery. It reads the Main Mini Cloud object through ABBY, validates the exact recovery preimage, removes only the certified legacy-tree suppression rule, delegates the atomic replacement to ABBY, and re-reads through ABBY for postimage verification.

## v0.1.0 boundaries

- ABBY is the filesystem authority.
- No host shell utility performs the replacement.
- No network dependency.
- No auto-activation.
- No arbitrary target argument.
- No Directory migration.
- No V5 activation.
- No Gaffer or terminal change.
- Source only; no executable is included.
